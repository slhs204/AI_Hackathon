# Project agent instructions

At session start, the owner-facing host must load and follow agentflow through supported skill discovery, honoring explicit owner opt-outs. If unavailable, report it; do not assume a path or install it. Delegates follow their assignments without activating agentflow.

Before work or review, read agentflow's references/project-rules.md from the resolved skill, then .agentflow/rules.md if present. Unavailable shared rules defer shared-record writes and invariant/review acceptance; report the gap and continue independent authorized work. Reading rules does not activate agentflow.
